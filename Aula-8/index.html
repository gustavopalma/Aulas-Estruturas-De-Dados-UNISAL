Filas

Filas - Conceito

  • Em diversas situações, os elementos devem ser processados na mesma ordem em que chegaram.
  • Esse comportamento aparece em filas de atendimento, impressão, mensagens, processos e requisições de rede.
  • Uma fila preserva a ordem de chegada.

Filas - Conceito

  • Uma fila é uma estrutura linear em que a inserção ocorre no final e a remoção no início.
  • Seu comportamento é conhecido como FIFO — First In, First Out.
  • O primeiro elemento inserido será o primeiro removido.

Filas - Conceito

Filas - Estrutura

  • A implementação reutiliza a mesma estrutura de nó usada em listas e pilhas.
typedef struct No
{
    int dado;
    struct No *proximo;
} No;

Filas - Início e Fim

  • inicio: primeiro elemento, que será removido;
  • fim: último elemento, após o qual ocorrerá a inserção.

Filas - Representação

typedef struct
{
    No *inicio;
    No *fim;
} Fila;

Fila fila = { .inicio = NULL, .fim = NULL };

Quando a fila está vazia, os dois ponteiros são NULL.

Filas - Enqueue

  • Adiciona um elemento no final.
  • O novo nó aponta para NULL.

Filas - Enqueue

void enqueue(Fila *fila, int valor)
{
    No *novo = malloc(sizeof(No));
    if (novo == NULL) return;

    novo->dado = valor;
    novo->proximo = NULL;

    if (fila->inicio == NULL)
        fila->inicio = fila->fim = novo;
    else
    {
        fila->fim->proximo = novo;
        fila->fim = novo;
    }
}

Filas - Dequeue

  • Remove o elemento localizado no início.
  • Se o último elemento for removido, início e fim voltam para NULL.

Filas - Dequeue

int dequeue(Fila *fila, int *valor)
{
    if (fila->inicio == NULL) return 0;

    No *removido = fila->inicio;
    if (valor != NULL) *valor = removido->dado;

    fila->inicio = removido->proximo;
    if (fila->inicio == NULL) fila->fim = NULL;

    free(removido);
    return 1;
}

Filas - Front / Peek

  • Consulta o primeiro elemento sem removê-lo.

Filas - Front / Peek

int front(const Fila *fila, int *valor)
{
    if (fila->inicio == NULL) return 0;
    if (valor != NULL) *valor = fila->inicio->dado;
    return 1;
}

Filas - Verificação

int filaVazia(const Fila *fila)
{
    return fila->inicio == NULL;
}

Filas - Percurso

const No *atual = fila->inicio;
while (atual != NULL)
{
    printf("%d ", atual->dado);
    atual = atual->proximo;
}

Filas - Liberação

Filas - Liberação

void liberarFila(Fila *fila)
{
    while (fila->inicio != NULL)
    {
        No *temp = fila->inicio;
        fila->inicio = fila->inicio->proximo;
        free(temp);
    }
    fila->fim = NULL;
}
