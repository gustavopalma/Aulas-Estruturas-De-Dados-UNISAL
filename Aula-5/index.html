Persistência de Dados Com Arquivos

  • Arquivos são uma das formas de persistência de dados mais simples existentes
  • Arquivos São suportados pela maioria das Linguagens de Programação
  • Para Ler um arquivo, basta saber como ele foi escrito

Persistência de Dados Com Arquivos - Arquivos de Texto

Um dos modelos mais simples de persistência de dados é o arquivo de modo texto

Vantagens
  • Arquivos simples
  • Humanamente Legíveis
  • Podem ser editados com qualquer editor de texto
Desvantagens
  • Informações não confiáveis
  • Não Recomendáveis para uso em produção
  • Não podem ser usados para lidar com informações sensíveis
  • Mais dificeis de tratar, quando a edição e manutenção dos dados

Persistência de Dados Com Arquivos - Arquivos de Texto

  • Escrenvendo Arquivos de Texto
          

typedef struct _pessoa {
    char nome[100];
    int idade;
    char endereço[100];
} pessoa;

int main() {
  pessoa p;
  FILE *arquivo;
  //...
  fgets(p.endereco, sizeof(p.endereco), stdin);
  //...
  // abre o arquivo em modo escrita ("w" = write)
  arquivo = fopen("dados.txt", "w");

  if (NULL == arquivo) {
    printf("Erro ao abrir o arquivo!\n");
    return 1;
  }
    
  fprintf(arquivo, "Nome: %s\n",p.nome);
  fprintf(arquivo, "Idade: %d\n", p.idade);
  fprintf(arquivo, "Endereço: %s\n", p.endereco);

  // força a escrita dos dados
  fflush(arquivo);
  // fecha o arquivo, evita erros de concorrência
  fclose(arquivo);
  return 0;
}

Persistência de Dados Com Arquivos - Arquivos de Texto

  • Tipos de Abertura do Arquivo
    • "w" - Arquivo no modo escrita, apaga o conteúdo anterior do arquivo, se existir
    • "a" - Arquivo no modo escrita, adiciona mais dados ao final do arquivo
    • "r" - Abre o arquivo no modo somente leitura
  • com exceção do modo "r", todos os outros criam o arquivo, caso ele não exista

  • Lendo Arquivos de Texto
          
int main() {
    FILE *arquivo;

    // abre o arquivo em modo leitura ("r" = read)
    arquivo = fopen("dados.txt", "r");

    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo!\n");
        return 1;
    }
    
    printf(" ----- Dados Gravados  ----- \n");
    char linha[100];
    while (fgets(linha, sizeof(linha), arquivo) != NULL) {
        printf("%s", linha);  // imprime cada linha lida
    }
    printf(" ----- Dados Gravados  ----- \n");
    fclose(arquivo);
    return 0;
}

Persistência de Dados Com Arquivos - Arquivos Binários

  • Outro modelo simples de persistência de dados, e computacionalmente simples para a manutenção, é o arquivo binário
Vantagens
  • Computacionalmente Legível (formatado)
  • Mais seguro, quando comparado ao Arquivo de texto
  • geralmente só podem ser editados pelos programas que os criaram
Desvantagens
  • Informações não confiáveis
  • Não podem ser usados para lidar com informações sensíveis
  • Fácilmente corruptíveis

typedef struct _pessoa {
    long id; // para dos dados indexação
    char nome[100];
    int idade;
    char endereco[100];
} pessoa;    

int main() {
    pessoa p;
    FILE *arquivo;
    //...
    // abre o arquivo em modo escrita, preservando dados antigos, em modo binário ("ab" = append + binario)
    arquivo = fopen("dados.dat", "ab");

    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo!\n");
        return 1;
    }

    // escreve algumas informações no arquivo
    fwrite(&p, sizeof(pessoa), 1, arquivo);

    // fecha o arquivo (muito importante!)
    fflush(arquivo);
    fclose(arquivo);

    return 0;
}

  • Lendo Arquivos binários
          
typedef struct _pessoa {
    long id; // para dos dados indexação
    char nome[100];
    int idade;
    char endereco[100];
} pessoa;

int main() {
    pessoa p;
    FILE *arquivo;

    // abre o arquivo em modo leitura binária ("rb" = read + binary)
    arquivo = fopen("dados.dat", "rb");

    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo!\n");
        return 1;
    }
    
    printf(" ----- Dados Gravados  ----- \n");
    while (fread(&p, sizeof(pessoa), 1, arquivo)) {
        printf("ID: %ld | Nome: %s | Idade: %d | Endereço: %s\n",
               p.id, p.nome, p.idade, p.endereco);
    }
    printf(" --------------------------- \n");
    fclose(arquivo);
    return 0;
}
