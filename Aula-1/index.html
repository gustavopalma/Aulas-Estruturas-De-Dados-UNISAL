Porque Linguagem C?

Porque Linguagem C?

  • Muitos podem pensar que a Linguagem de programação C, é uma Tecnologia obsoleta, muito difícil e extremamente ultrapassada, contudo isso não é verdade
  • A Linguagem de programação C, é considerada uma linguagem clássica, afinal faz 50 anos que ela foi criada. Contudo, isso não significa que ela não é atualizada
  • A última versão da linguagem C, a C23 foi lançada em 2024, o que faz dela uma linguagem atual e amplamente utilizada em diferentes ambientes indo desde a criação de sistemas operacionais até o desenvolvimento de sistemas embarcados e aplicações de alto desempenho

Porque Linguagem C?

  • A linguagem C foi pensada para ter um nível baixo de abstração, mantendo-a próximo ao hardware;
  • Essas duas características principais, a tornam a melhor escolha para o ensino de técnicas de programação e demonstração de conceitos
  • Durante as aulas vocês podem usar qualquer ambiente de desenvolvimento e qualquer compilador C, nós vamos nos ater as bases e a copreensão dos principais recursos

Tipos Primitivos de dados

  • Os tipos primitivos são os tipos de dados fundamentais fornecidos pela linguagem C. Eles representam valores básicos, como números inteiros, números de ponto flutuante e caracteres, servindo como base para a construção de estruturas de dados mais complexas.
  • Cada tipo possui características próprias, como tamanho em memória, faixa de valores e precisão, fatores que influenciam diretamente o desempenho e o consumo de memória de um programa. A escolha do tipo adequado é uma decisão importante durante o desenvolvimento, pois permite representar os dados de forma eficiente e segura.
  • Na linguagem C, os tamanhos dos tipos podem variar de acordo com a arquitetura do computador e o compilador utilizado. Entretanto, atualmente, em sistemas de 64 bits, existe um conjunto de tamanhos que se tornou amplamente adotado e que será utilizado como referência ao longo desta disciplina.

Tipos primitivos de dados e o C99

  • Embora a linguagem C possua tipos como char, short, int e long, o tamanho desses tipos pode variar de acordo com a arquitetura e o compilador utilizado. Para resolver esse problema, o padrão C99 introduziu o cabeçalho stdint.h, que define tipos inteiros com tamanhos fixos e portáveis.
  • Esses tipos são criados utilizando a palavra-chave typedef, que permite definir um novo nome (apelido) para um tipo já existente. Dessa forma, um programador pode utilizar tipos como uint8_t ou int32_t sabendo exatamente quantos bits eles ocupam, independentemente da plataforma em que o código será compilado.
  • Essa padronização tornou o desenvolvimento de bibliotecas, sistemas operacionais, sistemas embarcados e protocolos de comunicação muito mais seguro e portável.

Então, Como criar novos tipos de dados, portáveis ou mais amigáveis?

Então, Como criar novos tipos de dados, portáveis ou mais amigáveis?

  • A resposta é simples, não criamos. Nós apenas criamos apelidos (alias) para tipos existentes, o que facilita o entendimento de outros desenvolvedores.
  • A avaliação dos apelidos (alias), é feita durante a etapa de pré processamento:
          
//...
typedef unsigned char uint8_t;
typedef signed int int32_t;
//...
